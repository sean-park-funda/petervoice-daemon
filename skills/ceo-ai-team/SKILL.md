# CEO AI Team — 직원 없는 회사의 부서 세팅

소규모 회사 대표의 회사에 **독립 프로젝트 5개**를 프로비저닝한다. 각 프로젝트가 부서이고, 각 부서의 에이전트가 **팀장**이다.

```
대표
 ├── 부사장실 (vp)        ← 대표 단일 창구·비서 업무 + 다른 팀 모니터링·지시 대행
 ├── 회계팀 (accounting)  ← 세금계산서·증빙·신고 (팀장)
 ├── 법률팀 (legal)       ← 계약서 검토·표준 대비 (팀장)
 ├── 마케팅팀 (marketing) ← 채널·문안 (팀장)
 └── 영업팀 (sales)       ← 제안서·거래처 (팀장)
```

- 대표는 **각 팀장과 직접 대화**할 수 있다 (사이드바에서 프로젝트 전환).
- 부사장은 릴레이로 다른 팀에 지시를 전달하고 보고를 취합한다 — 대표가 부사장에게만 말해도 회사가 돈다.
- 각 팀장은 필요하면 **자기 프로젝트 하위에 브랜치로 팀원을 채용**한다 (브랜치 프롬프트로 역할 부여).

## 원칙
- 전문가 프롬프트는 이 스킬의 `prompts/` 에 **사전 리서치된 고정본**으로 내장 — 실행마다 리서치하지 않는다 (재현성: 누가 실행해도 같은 팀).
- **AI가 못 하는 것은 사용자 몫**으로 명확히 넘긴다: 계정 연동(OAuth)·API 가입·회사 정보 업로드. 완료 후 체크리스트로 안내.
- 승인 원칙 내장: 금액·발송·대외 노출은 전부 대표 승인 후 실행하도록 각 프롬프트에 포함돼 있다.

## 실행 흐름

### 1. 확인 (질문 최대 1개)
회사명만 확인한다: "팀을 만들 회사 이름이 뭔가요?" (이미 알면 질문 생략)

### 2. 프로젝트 5개 생성
```bash
API_URL=$(python3 -c "import json; c=json.load(open('$HOME/.claude-daemon/config.json')); print(c.get('api_url', 'https://www.peter-voice.site'))")
API_KEY=$(python3 -c "import json; print(json.load(open('$HOME/.claude-daemon/config.json'))['api_key'])")

# 5개 반복: (id, name) = (vp, 부사장실) (accounting, 회계팀) (legal, 법률팀) (marketing, 마케팅팀) (sales, 영업팀)
curl -s -X POST "$API_URL/api/projects" \
  -H "X-Api-Key: $API_KEY" -H "Content-Type: application/json" \
  -d '{"id": "vp", "name": "부사장실"}'
```
- id 는 영문 소문자·숫자·하이픈만. **이미 같은 id 가 있으면**(400/중복) `-2` 등 접미사를 붙이고, 이후 단계의 프로젝트 ID 명단에 실제 사용한 id 를 반영한다.
- 기존 프로젝트 목록은 `GET /api/projects` 로 먼저 확인 (중복 예방).

### 3. 각 프로젝트에 팀장 프롬프트 주입
`prompts/` 의 파일을 읽어 프로젝트 프롬프트로 넣는다 (PUT /api/prompts, body: `{"project": "id", "content": "전체 내용"}`):
- `vp` ← `vp-lead.md` (부사장실 — 아래 "명단 치환" 필수)
- `accounting` ← `accounting.md` / `legal` ← `legal.md` / `marketing` ← `marketing.md` / `sales` ← `sales.md`

**치환·부착 규칙**:
1. `vp-lead.md` 안의 `{{TEAM_ROSTER}}` 를 실제 생성된 프로젝트 id 명단으로 치환:
   ```
   - 회계팀: accounting / 법률팀: legal / 마케팅팀: marketing / 영업팀: sales
   ```
   `{{회사명}}` 도 치환.
2. 팀장 4개 프롬프트(회계·법률·마케팅·영업) 끝에 아래 **공통 조직 규약**을 그대로 덧붙인다 (`{{VP_ID}}` 는 부사장실 실제 id, `{{회사명}}` 치환):

```markdown
## 조직 규약 ({{회사명}})
- 당신은 이 부서의 **팀장**이다. 대표가 이 프로젝트에서 직접 지시하기도 하고, 부사장실(프로젝트: {{VP_ID}})이 대표를 대신해 릴레이로 지시하기도 한다.
- `[relay from:{{VP_ID}}]` 로 시작하는 메시지는 대표의 위임 지시다. 처리 후 **결과를 릴레이로 부사장실에 회신**하라 (POST /api/relay/message, to_project={{VP_ID}}, from_project=자기 프로젝트 id).
- 부사장실이 상태 보고를 요청하면 진행 중 업무·대기 중 승인·막힌 것 3줄로 회신.
- 금액·발송·대외 노출이 걸린 실행은 반드시 대표 승인 후. 승인 요청은 대표가 지금 보고 있는 창구(직접 대화면 채팅, 릴레이 지시면 부사장실 경유)로 올린다.
- 업무가 늘어 역할 분담이 필요하면 **이 프로젝트 하위에 브랜치로 팀원을 만든다** (POST /api/branches + 브랜치 프롬프트 PATCH — 역할·전문 분야를 프롬프트에 명시). 팀원 결과물의 최종 책임은 팀장인 당신에게 있다.
```

### 4. 지식 폴더 스캐폴드 + 표준 자료 자동 수집
프로젝트 디렉토리 루트는 현재 프로젝트 디렉토리의 부모 (`pwd` 의 상위 = projects 루트). 거기에 각 팀 프로젝트 폴더를 만들고 채운다:
```
{projects루트}/legal/docs/company/
  ├── contracts/   ← 회사가 주고받은 계약서 — 유저 업로드
  └── standards/   ← 표준계약서 모음 — ★스킬이 자동 수집
{projects루트}/sales/docs/company/products/    ← 상품·서비스 정의 — 유저 업로드
{projects루트}/accounting/docs/company/finance/ ← 거래처·정산 구조·신고 일정 — 유저 업로드
```
**표준계약서는 이 단계에서 에이전트가 직접 수집해 legal 의 standards/ 에 넣는다** (유저에게 묻지 않음 — 공개 자료라 바로 수집).
수집 방법 (2026-08-06 실검증 — 목록 페이지 스크래핑은 공공기관이 차단하므로 **직링크·검색 경유**로):
1. 웹 검색으로 "표준하도급계약서 hwp/pdf 다운로드" 직링크를 찾아 받는다 (예: 협회·기관이 게시한 직링크는 다운로드 됨 — 실검증: etis.or.kr 엔지니어링 표준하도급계약서 성공)
2. HWP 파일은 `hwp5txt` 로 텍스트 변환해 함께 저장 (없으면 `pip install pyhwp` 안내) — 팀이 읽을 수 있는 형태가 목적
3. 유형별(용역/NDA/하도급) 정리 + 각 파일에 출처 URL·수집일·개정연도 기재 (오래된 개정본이면 표기)
4. 다운로드가 막힌 소스는 출처 링크만 `standards/출처목록.md`에 정리하고 "미수집" 표시 — 팀 생성을 막지 않는다.

### 5. 사용자 할 일 안내 (반드시 이 체크리스트로 마무리)
생성 보고와 함께 아래를 안내한다. 각 부서는 사이드바 프로젝트 링크로 안내한다: `[부사장실](/?project=vp)` 형식 (실제 생성 id 사용). **AI가 대신 못 하는 것들이며, 각 항목이 끝나야 해당 부서가 실전 투입된다:**

```
✅ 5개 부서 프로젝트가 생겼습니다. 이제 대표님이 하실 일:

□ 1. 구글 연동 (부사장실용 — 메일·캘린더) ★가장 먼저
     설정 → 외부 서비스 연결 → Google 로그인
□ 2. 쓰고 계시면 연결하세요 — 팀 전체가 강해집니다:
     · 노션: 회의록·문서를 팀이 직접 읽습니다 (회의록 → 할 일 정리가 바로 가능)
     · 슬랙: 채널 요약·메시지 전달을 부사장이 합니다
     (안 쓰시면 건너뛰세요 — 없어도 팀은 돌아갑니다)
□ 3. 팝빌 가입·연동 (회계팀용 — 세금계산서 실발행)
     popbill.com 사업자 가입 → 연동신청(API Key는 시크릿 패널에) → 공동인증서 등록
□ 4. 회사 정보 업로드
     법률팀 docs/company/contracts/ 에 계약서, 영업팀 products/ 에 상품 소개,
     회계팀 finance/ 에 거래처·정산 방식 메모 (형식 자유 — 팀이 읽고 정리합니다)
□ 5. (선택) SNS 계정 연결 (마케팅팀용)
□ 6. (선택) 유튜브 채널을 운영 중이거나 시작하려면:
     전담 운영자를 추가하세요 → "유튜브 운영자 만들어줘" (youtube-channel-manager 스킬)

각 팀장과는 사이드바에서 프로젝트를 전환해 직접 대화하시면 됩니다.
끝나면 부사장실에서 이렇게 말해보세요: "오늘 할 일 정리해서 보고해줘"
```

## 주의
- 프로젝트 생성 직후 데몬이 새 프로젝트를 인식하기까지 잠깐(수 분) 걸릴 수 있다 — 첫 메시지가 늦게 응답되면 정상.
- API 키·인증서 값을 채팅에 붙여넣지 않도록 안내 — 시크릿 패널 사용.
- 과거 버전이 만든 "OO AI 팀"(expert-team, 한 프로젝트에 멤버 오버레이)이 남아 있으면 유저에게 삭제 여부를 확인 후 정리한다.
