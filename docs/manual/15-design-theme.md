# 15. 디자인 및 테마

## 다크/라이트 모드

### 구현

- **라이브러리**: `next-themes`
- **방식**: CSS 클래스 기반 (`attribute="class"`)
- **기본 테마**: 다크
- **시스템 환경설정**: 지원 (자동 감지)
- **저장**: localStorage + 시스템 설정

### ThemeProvider

```tsx
// components/ThemeProvider.tsx
<ThemesProvider attribute="class" defaultTheme="dark" enableSystem>
  {children}
</ThemesProvider>
```

### 토글 위치

설정 패널 (유저명 클릭 → Settings 탭) 내에 테마 토글 버튼.

### Tailwind 설정

```js
// tailwind.config.ts
darkMode: "class",
theme: {
  extend: {
    colors: {
      // 채팅 말풍선 등 커스텀 색상
    }
  }
}
```

## 헤더 구조

```
[유저명 🟢] ────── [프로젝트명 ▼] [🔗] [⚙] ────── [🎤]
  ↑                    ↑           ↑     ↑           ↑
상태패널            프로젝트     배포URL 프로젝트    음성모드
(클릭→설정)        드롭다운     이동    설정        토글
```

### 상태 표시 (유저명 옆)

| 상태 | 표시 |
|------|------|
| 온라인 (데몬 정상) | 🟢 |
| 작업 중 | 🔄 (스피너) |
| 오프라인 (60초+ 무응답) | 🔴 |

## 메시지 스타일

### 사용자 메시지

- 배경: 파란색 (`bg-blue-600`)
- 텍스트: 흰색
- 정렬: 우측
- 모서리: 둥근 모서리 (좌상단만 각진)
- 링크: 밝은 색상으로 구분

### 봇 메시지

- 배경: 회색 (`bg-gray-700` 다크 / `bg-gray-100` 라이트)
- 텍스트: 기본 색상
- 정렬: 좌측
- 모서리: 둥근 모서리 (우상단만 각진)

### 툴 로그

- 접힌 상태: 작은 폰트, 회색 카드
- `"N개 도구 사용"` / `"N개 도구 사용 중"`
- 클릭으로 펼치기

### 애니메이션

- 메시지 등장: fade-in + scale (Framer Motion)
- 스크롤 다운 인디케이터: 부드러운 전환

## 프로젝트 드롭다운 스타일

| 항목 | 스타일 |
|------|--------|
| 현재 프로젝트 | 파란 보더 |
| 1시간 내 대화 | 노란 하이라이트 배경 |
| Unread | 우측 빨간 점 |
| 작업 중 | 좌측 회전 스피너 |
| 마지막 메시지 | 작은 회색 텍스트 |

## 사이드바

- **할일/캘린더**: PC에서 좌측 사이드바 (기본 폭의 2배)
- **열기**: 상단 바의 일정/할일 버튼 클릭
- **모바일**: 전체 화면 오버레이

## 음성모드 오버레이

- 전체 화면 불투명 배경 (채팅 UI 가림)
- 파형 시각화 (볼륨 바)
- 상태별 색상 변화
- 하단 버튼: 1줄로 간소화

## 브랜딩

- 서비스명: **Peter Voice** (구 "손홀봇"에서 변경)
- 로그인 페이지, 탭 타이틀 등 통일

## 백버튼 관리

모바일 UX:
- 채팅창에서 백버튼 → "로그아웃하시겠습니까?" (바로 로그아웃 방지)
- 모달/드롭다운 열린 상태에서 백버튼 → 모달 닫기
- 모달 우선순위: fork → picker → project → taskInput → status → secrets → documents

## 반응형

- `768px` 기준으로 모바일/PC 분기
- 모바일: 전체 너비, 사이드바 오버레이
- PC: 채팅 + 사이드바 + 문서 패널 분할
- 문서 패널: PC는 좌우 분할, 모바일은 전체 화면
