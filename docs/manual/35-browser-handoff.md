# 35. 원격 로그인 인계 (browser-handoff)

## 개요
브라우저 자동화(agent-browser 등) 중 로그인/2FA 벽에 막히면, **browser-handoff 스킬**로
서버 브라우저 화면을 유저의 폰/PC에 넘겨 유저가 직접 로그인하게 하고, 세션(쿠키)을
이어받아 작업을 계속한다. "로그인이 필요합니다"로 작업을 멈추는 것은 잘못된 처리다.

## 에이전트 사용 지침
- 트리거: 로그인이 필요한 사이트 작업, 세션 만료, 2FA 요구
- Skill 도구로 `browser-handoff` 호출 → 스킬이 접속 링크 생성 절차를 안내
- 유저에게 링크를 채팅으로 전달하고, 로그인 완료 답을 받으면 작업 재개
- 유저가 비밀번호를 채팅에 적으려 하면 이 기능으로 대신할 것을 권할 것 (자격증명 위생)

## 요구사항
- 번들 스킬 `browser-handoff` **pv_version 1.1.0 이상** (구버전은 클라우드 전용 경로만
  참조해 맥미니에서 동작 불가 — 데몬 재시작 시 SkillsSyncer가 최신 번들로 교체)
- 관련 BP 카드: `browser-handoff` (설정 > Best Practice)

## 유저 안내 문서
사용자용 설명: 유저 매뉴얼 20장 (로그인은 내가 대신)
