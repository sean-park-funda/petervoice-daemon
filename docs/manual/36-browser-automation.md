# 36. 브라우저 자동화 동시 사용 (공유 브라우저 vs 전용 세션)

> 작성: 2026-08-20 · 근거: login-manager 프로젝트 실측 (탭 덮어쓰기 사고 3건 직후)
> 관련 장: [35. 원격 로그인 인계](./35-browser-handoff.md) · 상세 사용법은 `agent-browser` 스킬 문서

## 배경

한 머신에서 여러 프로젝트·브랜치의 에이전트가 동시에 브라우저를 쓴다. 지금까지는 모두
공유 브라우저(CDP 9222) 하나에 붙어 작업했는데, 2026-08-20 하루에만 서로의 탭을 덮어쓰는
사고가 3건 발생했다.

- infohub #7 — 남의 탭을 자기 페이지로 오인해 오진
- petervoice-cloud #4 — 계약 폼 작성 중 페이지가 바뀌어 중단
- infohub #8 — login-manager의 사이트 순회에 작업이 밀려 중단

## 실측으로 확인된 사실 3가지

### ① 공유 브라우저의 활성 탭 포인터는 접속자 전원이 공유한다

`--session` 으로 세션을 나눠도 소용없다. 다른 에이전트가 `open <url>` 을 실행하면 활성 탭이
그쪽으로 이동하고, 새 탭을 만든 쪽이 그 순간 활성이 되어 이후 명령을 받아간다.

**완화책**: `tab new` 로 내 탭을 만들어 탭 id(tN)를 확보한 뒤, **매 명령 직전 `tab tN`** 으로
내 탭을 다시 활성화한다. 짧은 조회에는 충분하지만 완전한 격리는 아니다.

### ② 별도 CDP 포트로는 격리되지 않는다

9223, 9871 로 각각 새 크롬을 띄워 봤으나 두 번 다 몇 초 만에 다른 에이전트(designer)의
페이지가 그 포트로 들어왔다. agent-browser 가 실행 중인 CDP 브라우저를 자동 탐색해 붙기
때문이다. **포트 분리는 해법이 아니다.**

### ③ 해법은 agent-browser 자체 세션 격리다

`--session <이름>` 은 CDP 를 거치지 않고 세션마다 독립 브라우저 인스턴스를 만든다
(쿠키·스토리지 분리). `--restore <키>` 를 함께 쓰면 쿠키가 파일로 주기 저장돼 인스턴스가
죽어도 복원된다.

```bash
agent-browser --session <작업명> --restore <작업명> open <URL>
```

## 운영 정책

| 작업 성격 | 사용할 것 |
|---|---|
| 짧은 조회 (페이지 하나 읽고 끝) | 공유 브라우저 `--cdp 9222` + 매 명령 전 `tab tN` 고정 |
| 오래 걸리는 작업 (폼 작성, 결제, 다단계 플로우) | 전용 세션 `--session <작업명> --restore <작업명>` |
| 로그인이 필요한 작업 | login-manager 에 릴레이로 요청 (세션명 명시) |

로그인이 필요한 전용 세션은 login-manager 가 해당 세션명으로 로그인해 넘겨준다
(2026-08-20 pv4-inicis 사례). 사이트별 로그인·복구 노하우는 login-manager 프로젝트의
`docs/sites.md` 에 축적된다.

## 구글 로그인과 헤드리스 문제

구글은 **헤드리스 브라우저에서 로그인을 차단**한다 ("브라우저 또는 앱이 안전하지 않을 수
있습니다"). 그래서 맥미니 공유 브라우저는 headful(일반 창) 모드로 운영한다.

구글 세션이 죽으면 X·애드센스·슬랙 로그인이 함께 죽고, 복구에 Sean 의 원격 데스크톱 로그인이
필요하다.

**조치 완료 (2026-08-20, browser-handoff 1.3.0)**: `start-browser.sh` 는 기본값이 여전히
`--headless=new` 지만, **macOS 이고 GUI 콘솔 사용자가 있으면** 그 플래그를 비워 일반 창으로
띄운다. 화면이 없는 클라우드 컨테이너·리눅스는 헤드리스를 유지해야 하므로 고정하지 않고
조건부로 둔 것이다. 헤드리스가 아닐 때는 첫 탭을 "피터보이스 공유 브라우저" 랜딩 페이지로
띄워, 고객 화면에 갑자기 뜬 창이 무엇인지 알 수 있게 한다.

**남은 한계**: 콘솔에 로그인한 사용자가 없는 상태(재부팅 직후 로그인 전 등)에서 기동되면
판정이 거짓이 되어 헤드리스로 뜬다. 그 경우 구글 로그인이 막히므로, 사람이 로그인한 뒤
브라우저를 다시 띄워야 한다.
