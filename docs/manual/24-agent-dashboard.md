# 24. 에이전트 대시보드 (/agents)

## 개요

유저의 모든 에이전트(프로젝트)를 한눈에 보고 관리하는 대시보드 페이지. 에이전트 상태, 모델, 시스템 프롬프트를 웹에서 직접 확인/편집 가능.

## 접근 경로

- URL: `/agents`
- 채팅 왼쪽 상단 관리 메뉴 → "🤖 에이전트 대시보드"

## 레이아웃

```
┌──────────────────────────────────────────────┐
│ 에이전트 대시보드                              │
├────────────┬─────────────────────────────────┤
│            │ [공통 프롬프트]  (접기/펼치기)     │
│ 에이전트    │                                 │
│ 목록       │ 에이전트 이름                     │
│            │ 상태: active                     │
│ ● peter-   │ 모델: claude-sonnet-4-5          │
│   voice    │                                 │
│ ○ thegrim  │ [시스템 프롬프트]                 │
│ ○ cocktail │ (편집 가능 textarea)              │
│            │                                 │
│            │ [저장]                           │
└────────────┴─────────────────────────────────┘
```

## 기능

### 에이전트 목록 (좌측)

각 에이전트 카드에 표시되는 정보:
- 프로젝트 이름
- 현재 상태 (active/inactive)
- 사용 모델
- 프롬프트 미리보기 (첫 몇 줄)
- 하위 에이전트(브랜치) 수

### 상세 패널 (우측)

에이전트 클릭 시 표시:
- 에이전트 기본 정보 (이름, 모델, 상태)
- **시스템 프롬프트 편집기**: textarea로 직접 수정 → 저장

### 공통 프롬프트 편집

대시보드 상단에 공통 프롬프트(`_common`) 섹션:
- 접기/펼치기 토글
- 인라인 편집 + 저장 버튼
- 모든 에이전트에 공유되는 프롬프트를 한곳에서 관리

### 관리자 기능

관리자(`admin` 역할)는 드롭다운으로 **다른 유저를 선택**하여 해당 유저의 에이전트 목록을 조회할 수 있음. 고객 지원/디버깅 용도.

## API

| 메서드 | 경로 | 설명 |
|--------|------|------|
| GET | `/api/agents` | 에이전트 목록 (프로젝트 + 프롬프트 + 브랜치 수) |
| PUT | `/api/agents/prompt` | 에이전트 프롬프트 수정 |
| GET | `/api/agents/users` | 유저 목록 (관리자용) |
